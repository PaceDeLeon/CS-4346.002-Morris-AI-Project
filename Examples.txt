CS 4346 Morris Game, Variant - MINIMAX vs. ALPHA-BETA examples
==============================================================

For each case, MINIMAX and ALPHA-BETA were run on the same input board at
the same depth. Both use the same move generator, the same handout static
estimation, the same move order, and the same tie-break (the first best
move found is kept). As expected, both return the same board position and
the same estimate; ALPHA-BETA evaluates fewer positions in every case.

Command format:
  python <program>.py <input board file> <output board file> <depth>

Playing for Black (Part III)
============================

MiniMaxOpeningBlack.py and MiniMaxGameBlack.py use the color-swap method
from the handout: swap W and B in the input board, compute White's best
move, then swap the colors of the selected board back.

Because the search is done on the swapped board, the printed MINIMAX
estimate is from Black's point of view (positive values favor Black).

Example 6 - MiniMaxOpeningBlack.py, board2.txt, depth 3
  Input:          WWxBBBBxxWxxxxxxxxxxxxx
  Board Position: WWBBBBBxxWxxxxxxxxxxxxx
  Positions evaluated by static estimation: 3840
  MINIMAX estimate: 2
  Black places at g0, blocking White's a0-d0-g0 mill.

Example 7 - MiniMaxGameBlack.py, depth 3
  Input:          xxxxxBxWWWWWBBBBxxxxxxx
  Board Position: xxxxxBxWWWWWxBBBxxxBxxx
  Positions evaluated by static estimation: 685
  MINIMAX estimate: 993
  Black moves f3 -> f5.
